# Surface-Crack-Detection-Using-CNN
A detailed project based on Convolutional Neural Network (CNN) which identifies the cracks

Surface Crack Detection Using Deep Learning

📌 About

A computer vision project that detects cracks on concrete and other surfaces using image processing and deep learning techniques. It helps identify potential structural damage and supports faster inspection.

 Technologies

- Python
- TensorFlow / Keras
- OpenCV
- NumPy

 Features

- Detects surface cracks from images.
- Classifies cracked and non-cracked surfaces.
- Supports infrastructure inspection.

 Applications

- Buildings
- Roads
- Bridges
- Concrete structures
